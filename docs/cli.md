# Meow CLI

The CLI is distributed as `@meowcode/cli` and exposes a single executable:

```bash
meow
```

Interactive sessions use natural prompts by default. Slash commands control workspace, providers, models, router policy, context, files, tests, reviews, and MCP tools.

## Commands

- `/help`
- `/model`
- `/provider`
- `/providers`
- `/models`
- `/router`
- `/workspace`
- `/project`
- `/history`
- `/context`
- `/files`
- `/settings`
- `/login`
- `/logout`
- `/sync`
- `/mcp`
- `/agents`
- `/review`
- `/refactor`
- `/test`
- `/docs`
- `/clear`
- `/exit`
